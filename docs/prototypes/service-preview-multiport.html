交互说明
  • 终端 标签：切回终端视图（预览仍在后台运行，不断开）。
  • 预览 :PORT 标签：切到该预览。左侧圆点 = 连接状态（绿=正常，黄闪=重连中）。多个预览并列，点击切换。
  • +：弹出「加端口」表单，填端口即新开一个独立预览并激活；高级里可为它再挂路径映射。
  • ↗ 打开系统浏览器 / ⧉ 复制 URL / ✕ 关闭：作用于当前活跃预览（变体 A 独立成簇；变体 B 内联在活跃标签里）。关掉最后一个预览后，控制区回到「仅 host 徽标 + 天线按钮」的初始态。
  • host 徽标（📡 attson@… · 642d4ae9）：常驻最右，开不开预览都在，天线按钮也可用来新开预览。
