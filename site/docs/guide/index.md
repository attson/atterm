# AT Term 产品手册

这套手册按你要完成的任务组织。第一次使用时先安装桌面端并熟悉本地工作区；需要离开电脑继续长任务时，再选择 Relay 或 Peer Space 接入 Web、移动端或另一台桌面客户端。

## 选择你的使用路径

| 目标 | 从这里开始 | 你会完成什么 |
|---|---|---|
| 把 AT Term 当作本地终端和 SSH 工作台 | [安装与快速上手](/guide/getting-started) | 安装桌面端、创建会话，并了解本地优先的工作方式 |
| 从手机、浏览器或另一台电脑继续任务 | [远程接管与会话侧栏](/guide/remote-takeover) | 选择远程方式、查看会话、取得控制权并恢复任务 |
| 部署自己的账号服务 | [部署 Relay](/guide/deploy-relay) | 配置 TLS、账号、管理后台、存储和多实例 |
| 建立无账号的可信设备组 | [部署 Rendezvous](/guide/deploy-rendezvous) | 配置发现与加密信令，让设备建立点对点连接 |
