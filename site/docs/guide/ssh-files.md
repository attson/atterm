# SSH 与文件

桌面端既是本地终端，也是 SSH 工作台。主机配置、密钥引用、跳板和端口转发集中在标签栏的 **SSH hosts** 面板；连接后，SSH 会话和普通 shell 一样进入标签页、侧栏与恢复流程。

## 添加和连接主机

1. 点标签栏右侧的 SSH 图标打开主机面板。
2. 新建主机，填写名称、地址、端口和用户名；按需要选择密码或已导入的私钥。
3. 如需跳板、代理或端口转发，在保存前配置对应路由与 tunnel。
4. 保存后点主机建立会话。不同主机可以单独设置终端主题和外观。

桌面端还提供两个迁移入口：

- **Import from `~/.ssh/config`**：预览并选择可导入的 Host；凭据不会从 config 自动猜测。
- **Import from Termius**：先完全退出 Termius，再选择数据目录并预览主机、密钥和 Snippet。导入只在桌面端提供；`localKey` 是 Termius 钥匙串中的 base64 密钥，不是账号密码。

配置导出不会包含 SSH 密码或私钥。把配置导入另一台机器后，需要重新添加这些凭据。

## 文件浏览、预览与编辑

展开工作区右侧面板即可打开文件浏览器。它会跟随当前 pane，在本地 shell 中访问本机文件，在 SSH 或远程会话中通过该会话访问对应主机。

![AT Term 文件浏览器与文件预览](/manual/file-explorer.png)

常见操作：

- 展开目录、按文件名搜索和排序。
- 预览文本、Markdown、代码和支持的图片。
- 在内置编辑器修改文本文件并保存。
- 新建、重命名、下载或删除文件；远程目录删除不会提供“回收站”语义，危险操作应回到终端确认路径后执行。
- 终端输出中的本地路径可以直接在文件浏览器中定位。

## 从客户端发送文件或图片

浏览器和移动端可通过终端辅助工具显式选择图片或文件，发送到当前远程会话。发送前必须同时满足：

1. 会话已经 attach。
2. 当前客户端是 driver，而不是只读 viewer。
3. 桌面端把该会话的远程权限设为 `full`。

`view` 只能观看，`control` 可输入和调整终端，`full` 才允许文件、图片和文件系统操作。权限细节见 [跨设备客户端](/guide/remote-clients) 与 [端到端加密与安全](/guide/e2ee)。
